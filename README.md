# Студия керамики «Лепко» — Иркутск

Лендинг для студии керамики. Дизайн выполнен в мобильном формате (Instagram-стиль), адаптирован под смартфоны.

## 🌟 Особенности
- **Мобильный веб-дизайн**: лента карточек 4:5, «сторис»-навигация, горизонтальные свайп-карусели.
- **Умная запись (Bottom Sheet)**: единая шторка для всех кнопок «Записаться».
- **Web Share API**: автоматическое формирование текста заявки и вызов системного меню «Поделиться» для отправки в мессенджеры без необходимости копировать/вставлять текст вручную.
- **Генератор сертификатов**: интерактивный талон, который обновляется в реальном времени по мере заполнения формы.
- **Ленивая загрузка карты**: Яндекс.Карты подгружаются только при прокрутке до блока контактов.

## 🛠 Стек
- HTML5 (семантическая верстка, Schema.org)
- CSS3 (Custom Properties, Grid, Flexbox, медиа-запросы)
- Vanilla JavaScript (без зависимостей и фреймворков)

## 🚀 Локальный запуск
Просто откройте файл `index.html` в браузере. Для проверки Web Share API (меню «Поделиться») рекомендуется использовать мобильное устройство или эмуляцию в DevTools (Chrome) с включенной поддержкой сенсорного экрана.

## 📂 Структура
- `index.html` — разметка страницы
- `css/style.css` — стили
- `js/main.js` — логика шторки записи, талона, карусели и карты
- `img/` — графика и фотографии
