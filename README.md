# Студия керамики «Лепко» — Иркутск

Лендинг для студии керамики. Дизайн выполнен в мобильном формате (Instagram-стиль), адаптирован под смартфоны.

## 🌟 Особенности
- **Мобильный веб-дизайн**: лента карточек 4:5, «сторис»-навигация, горизонтальные свайп-карусели.
- **Умная запись (Bottom Sheet)**: единая шторка для всех кнопок «Записаться». Текст заявки формируется автоматически и копируется в буфер обмена для быстрой отправки в мессенджеры без ручного ввода.
- **Генератор сертификатов**: интерактивный талон, который обновляется в реальном времени по мере заполнения формы. При отправке данные сразу формируются в готовый текст заказа.
- **Ленивая загрузка карты**: Яндекс.Карты подгружаются только при прокрутке до блока контактов.
- **SEO и GEO-оптимизация**: настроены `robots.txt`, `sitemap.xml` и файл `llms.txt` для корректной индексации и взаимодействия с нейросетями (ChatGPT, DeepSeek, Qwen, YandexGPT и др.).

## 🛠 Стек
- HTML5 (семантическая верстка, Schema.org)
- CSS3 (Custom Properties, Grid, Flexbox, медиа-запросы)
- Vanilla JavaScript (без зависимостей и фреймворков)

## 🚀 Локальный запуск и размещение
Проект представляет собой статичный сайт и не требует серверной части (Backend) или сборки.

1. Для локального просмотра просто откройте файл `index.html` в браузере.
2. Для проверки работы копирования в буфер обмена (шторка записи) рекомендуется использовать локальный сервер (например, расширение Live Server в VS Code), так как некоторые браузеры блокируют Clipboard API при открытии файлов напрямую через `file://`.
3. **Размещение на хостинге**: просто загрузите все содержимое папки проекта (через FTP или файловый менеджер хостинга) в корневую директорию `public_html` (или `www`). Сайт сразу заработает.

## 📂 Структура
- `index.html` — разметка страницы
- `css/style.css` — стили
- `js/main.js` — логика шторки записи, талона, карусели и карты
- `img/` — графика и фотографии
- `sitemap.xml`, `robots.txt`, `llms.txt` — SEO и GEO файлы
